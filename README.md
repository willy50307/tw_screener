# 我的選股王

## 使用方式
桌面雙擊 **「我的選股王」** → 開啟獨立視窗。

- **⟳ 更新資料**：抓最新收盤資料並重新選股（App 開著的話，每天 15:30 也會自動更新）
- **查詢任一檔**：右上角輸入代號或名稱
- **☆ 加自選**：在 K 線上方，按一下加入或移除
- **⚙ 設定**：改 MACD 參數、縮短 %、成交量門檻、開關策略、自動更新時間…；「結束程式」也在這裡
- 左邊清單可以點欄位標題排序，用鍵盤 ↑↓ 切換股票

圖上 **粉色虛線** = 明日綠柱縮短 N% 的價格，**黃色虛線** = 明日黃金交叉的價格，**綠色箭頭** = 歷史進場訊號。
（價格是以 (高+低+2×收)/4 計算，跟 TradingView 指標相同）

## 處置 / 注意股（`notice.py`）
- **處置預測**：再被注意 1~2 次就會處置的股票、明日觸發注意的價位、最快處置日
- **處置股**：處置條件、剩餘交易日、出關日；點一下展開詳細資料
- **注意股**：今日被注意的款別、離處置還差幾次
- 法規依據：證交所、櫃買中心「公布或通知注意交易資訊暨處置作業要點」及異常標準詳細數據（115.08.03 版）
- 觸發價為估算（以今日全體/類股平均值試算；⑤⑥⑦⑨⑩⑫⑬ 需額外資料未估算），請以官方公告為準

## 處置歷史頁（`static/disp.js`）
115/8/10 新制後所有處置紀錄：處置前 5 日、處置中、出關後 5/10 日漲跌，K 線上紅色區塊是處置期間。

## 右側面板：回測 / 問 AI（`backtest.py`、`ai.py`）
- **回測**：用簡化的 Python 寫策略（格式說明在 `backtest.py` 最上面），可測「目前這一檔 / 全市場 / 處置歷史股票」。內建範本完整複製 TradingView 的 MACD(3,7,3) 單發狙擊版（含延遲停損、階梯停利）。
- **問 AI**：需要 Claude API 金鑰（console.anthropic.com 申請，依用量另外計費），在「⚙ 設定 → AI 助理」填入。可請它解讀回測、把 Pine Script 轉成回測格式（回答裡的程式碼有「套用到回測」按鈕）。
- 注意：回測會執行輸入的程式碼，只適合在自己電腦上使用；放上雲端給別人用之前要先關掉或加沙盒。

## 歷史資料與週期
- `python backfill.py`：抓全部歷史日K（上市 2004/2/11 起、上櫃 2008/1/2 起），中斷後再執行會接著抓
- K 線右上角可切換 **日 / 週 / 月 / 60分 / 5分**；日K可選半年、1年、3年、全部
- 週K、月K由日K合成；60分、5分K來自 Yahoo Finance（5分約近 60 天、60分約近 2~3 年，點開才抓）
- 價格為原始價（未還原除權息）

## 資料來源（免費、不需要 API key）
證交所（上市）、櫃買中心（上櫃）每日收盤行情、處置股、注意股。
資料存在 `data/stocks.db`，設定存在 `data/settings.json`。

## 新增策略條件
在 `strategies.py` 寫一個函式，加進 `STRATEGIES`，重開 App 後設定頁面就會出現開關。

## 程式架構
| 檔案 | 用途 |
|---|---|
| `launcher.pyw` | 桌面捷徑執行的程式：背景啟動伺服器 + 開視窗 |
| `app.py` | 後端伺服器（Flask）、自動更新排程 |
| `engine.py` | 選股引擎 |
| `indicators.py` / `strategies.py` | 指標、策略條件 |
| `data.py` | 抓資料、資料庫 |
| `settings.py` | 設定預設值 |
| `static/` | App 畫面（HTML / CSS / JS） |

之後要放上雲端：後端已經是標準網頁伺服器，用 `gunicorn app:app` 部署即可。
